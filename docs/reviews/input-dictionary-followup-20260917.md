# 再帰登録・キー操作・辞書設定の実機報告への対応

履歴資料です。対象時点の判定を保持しています。現在の仕様・残件との区別は [レビュー履歴の案内](README.md) を参照します。

## 受入仕様

2026-09-17 の追加報告を受け、次を修正範囲とします。候補・再帰登録の表示全体は [後続マイルストーン](https://github.com/yhayase/skk-android/milestone/1) に分け、今回の完了には含めません。

- 候補の末尾から入った再帰登録を C-g で抜けると、登録前の候補番号と単独／一覧表示に戻ります。候補がない場合は元の読みへ戻ります。
- 初期値は3候補目から `asdfjkl` の一覧です。設定画面で開始位置を1〜10候補目に変更できます。ページの候補数と開始位置は別です。
- かな入力の `-[]` は `ー「」`、半角カナでは `ｰ｢｣` です。その他の記号は全角・半角を選べます。数値登録の `#9` などを変えないため、その他の記号の初期値は半角です。句読点・丸括弧・波括弧の個別設定は優先します。
- 保存済みの値と同じ設定画面は破棄確認なしで閉じます。値を変えて元に戻した場合も同じです。未適用のカスタム規則編集を含む変更がある場合だけ確認します。
- 辞書の追加・更新・削除・有効化・並び替えと個人辞書の取り込みは下書きにまとめ、確定して閉じるときに一つのトランザクションと一回の辞書公開を行います。編集中は現在の辞書を使い続けます。破棄は保存済み辞書を変えません。

## 編集キーとリピート

Emacs 編集が有効な場合に次の追加キーを扱います。既存のかな切替・変換・確定・取消を優先し、パスワード欄と TYPE_NULL は迂回します。

| キー | 意味 |
| --- | --- |
| C-v / M-v | 入力先の PageDown／PageUp。候補選択中は候補一覧のページ境界へ移動します |
| M-< / M-> | 入力先の Ctrl+Home／Ctrl+End。内部ではバッファの先頭／末尾です |
| C-w / M-w | 入力先で選択した範囲の切り取り／コピー。選択がなければ変更しません |
| C-m | 入力先へ改行。未確定入力中は Enter 相当の確定だけを行います |

[GNU Emacs の操作一覧](https://www.gnu.org/software/emacs/tour/index.html) と [スクロール・キーリピートの説明](https://www.gnu.org/software/emacs/manual/html_node/emacs/Scrolling.html)、[DDSKK の基本操作](https://ddskk.readthedocs.io/ja/latest/05_basic.html) を参照しました。Android での配送は操作の種類で決めます。文字入力、左右・上下・行端・単語・ページの移動、文字削除・行末削除、候補巡回・補完を繰り返します。確定・取消・モード切替・登録・候補削除確認・切り取り・コピー・改行は長押しで再実行しません。アプリへ渡すキーのリピートは入力先が扱います。

Android の周辺文字取得の末端は文書末尾の証明になりません。自身の Unicode 編集計画を作れない左右移動だけは、同じ接続と選択位置を再確認したうえで入力先の方向キーへ委ねます。この経路では文字境界の扱いも入力先に依存します。ページ・文書端も入力先の標準キーを一度送ります。削除を方向キーなどで代行したり、失敗した変更を再送したりはしません。取得窓が移動した後の事後確認は、変更位置を含む共通区間と選択位置を検査します。標準 InputConnection に文書の原子的変更保証がない制約は引き続き残ります。

内部の読み・登録本文には選択範囲や画面単位のページ位置がないため、切り取り・コピー・画面スクロールを推測で実行しません。未対応の操作として通知します。

## 設定移行と辞書下書き

入力設定は版3で保存し、版1／2を読み取ります。以前のカスタムキーが新操作の初期キーと競合する場合は、以前の設定を保持し、新操作を未割当にします。追加した7操作は空欄で未割当にできます。メニュー開始位置の新しい初期値は3候補目、その他の記号は半角です。

辞書下書きは manager に保持し、画面回転で引き継ぎます。プロセス終了では未確定の下書きを破棄します。保存済み辞書は変わりません。解析済み文書の合計は3,200万文字までとし、同じソースの更新文書は置き換えて保持します。編集中の個人学習は継続します。個人辞書の上書き・取り込みで保存世代が変わった場合は競合として一括保存を拒否し、途中の操作だけを保存しません。保存後の公開だけに失敗した場合は保存済みとして区別し、同じ編集を二重適用しません。

## 独立レビューで修正した境界

- 新規追加→無効化→同じソースを再更新した場合、インポートより先に有効状態を適用しないよう操作の依存順を揃えました。
- 保存後の再構築中も下書きを参照可能にし、画面再作成が保存結果を失わないよう完了記録と一緒に引き渡します。
- 候補ページ移動を単純な候補数加減からページ開始位置へ変更し、最初の一覧を飛ばさないようにしました。
- 長文の周辺取得窓が移動しただけで、成功した C-m や移動を失敗と判定しないよう事後確認を修正しました。

試験結果と配布 APK は検証完了後に作業記録へ記載します。実機の操作感と後続 UI マイルストーンは、自動試験の成功だけで完了とはしません。
