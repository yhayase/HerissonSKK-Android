# 再帰登録 UI の再設計（2026-09-22）

## 目的と変更

登録本文・未確定の読み・変換候補を別々の説明行に並べていた表示を、一つの入力面へ統合しました。[設計](../registration-ui-design.md)に従い、本文のカーソル位置へ読み／候補を表示します。親の読みは一つだけ添え、階層番号・操作対象・常設の操作説明・通常の辞書状態を取り除きました。物理候補メニューは入力面の近く、登録・取消ボタンより前に表示します。

登録欄は入力フォーカスを取得せず、共通エンジンの状態を標準の AppCompatTextView へ描画します。独立した編集バッファや InputConnection は作りません。本文は省略せず折り返し、長文ではカーソルへスクロールします。未確定入力のない本文はタップでカーソルを移動できます。

## 分担とレビュー

表示面は Sol / medium、サービスとの統合は Terra / medium、コア・セッション境界とエミュレーター検証はメインが担当しました。別の Sol / medium が意味と入力境界をレビューし、指摘は実装担当とは別の担当が検証しました。

- 登録本文で C-j がモード復帰をせず終了していた指摘を別担当が確認しました。通常のかなモード復帰へ接続し、英数などからの復帰を試験しました。
- 保存中のタッチ取消が成功扱いでも動作しない指摘を別担当が確認しました。保存中は取消ボタンと専用操作を無効にし、物理 C-g の既存の保存待機取消を維持しました。
- 空読みを登録可能と扱う指摘は、現行コードで null のみを判定済みであるため、古い状態に対する指摘と確認しました。
- 本文タップの移動判定について別担当が終了座標と複数ポインタの不足を指摘し、表示担当も確認しました。移動途中の通知がなくても大きな変位をタップにしないよう修正し、独立した再レビューを受けました。

保存・取消・カーソル操作は、遅延処理後も表示時の登録状態と一致することを確認します。古い表示からの操作が子の登録や変更済み本文へ作用しないことを試験しました。

## 検証上の注意

Robolectric では幅による自動折返しが日本語・Latin 文字ともに再現されなかったため、単体試験は明示改行と全文の保持を検査します。日本語の自動折返しはエミュレーター画像で別途検査します。これは既知の回転試験の間欠的失敗とは別の、今回作成した試験の制約です。

利用者の指示に従い、既知の回転試験の flakiness の原因調査は行いません。
