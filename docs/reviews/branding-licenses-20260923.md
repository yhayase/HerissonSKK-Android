# 名称・アイコン・MIT 表示の反映（2026-09-23）

## 変更

アプリと IME の表示名を HerissonSKK (for Android) にし、所有者指定のハリネズミ画像を adaptive launcher icon に適用しました。原本とアプリ用 PNG のバイト列は同一です。画像自体を描き直さず、Android のリソース定義で白い背景と余白を付けています。アプリ ID は `se.haya.skk` のままです。

所有者の決定に従って、本体の独自コード・独自文書・指定アプリアイコンを MIT の対象にしました。ルート LICENSE と APK に同じ本文を収録し、第三者コード・外部辞書の条件は分けて明記しました。設定の「その他」→「ライセンス」から、MIT・適用範囲・第三者通知・Apache・ICU の本文をオフラインで表示できます。標準 Preference、既存の設定画面の枠、ScrollView と選択可能な TextView を使用します。

第三者通知は実行時依存68モジュールの座標・版と一致します。coroutines の版と不足していた依存物を訂正しました。設定画面の3ベクターは2担当が Material Icons の公式パスとの一致を確認し、Apache-2.0 の出典と変換・テーマ色の変更を明示しました。他のアイコンを見た目の類似だけで第三者由来と判定していません。

README とアイコンの由来記録には AI の関与を追加しました。開発は OpenAI Codex、画像制作は ChatGPT と Codex です。兄弟プロジェクトの原本と同一ハッシュであることを確認し、出典を記録しました。作者の仕様判断・確認・責任と、通常の入力内容を AI サービスに送信しないことも説明しています。

## 独立レビュー

UI と第三者通知は別担当が実装し、独立した担当がレビューしました。Material Icons の一致という指摘も別担当が検証しました。ライセンス画面の固定 dp 行高は拡大文字との不整合を検討して相対行間へ変更し、不要な独自スクロール処理を除きました。最終文書レビューで見つかった「名称・ライセンス反映が未実施」という古い現状記述は、別担当が現行の文書と照合してから訂正しました。
