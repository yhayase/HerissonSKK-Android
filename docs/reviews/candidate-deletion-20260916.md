# 候補削除・復元の実装レビュー

2026-09-16。K11の保存層に続き、入力中の確認、全由来の固定、数値テンプレート、Android接続、復元管理画面を実装しました。

## 検証した境界

- 候補表示時の個人世代と全由来を不変データとして保持し、Xで確認、yで保存、nまたは取消で戻ります。確認操作を入力先へ確定しません。
- 数値候補の由来は展開元テンプレートです。同じ表示へ収束した全テンプレートを対象にし、#4の内側参照を誤って削除しません。由来総数は4,096件までで、超過時は部分的な削除候補を公開しません。
- 保存中の再要求、遅延・重複完了、入力欄切替、外部カーソル移動、接続拒否、学習禁止、再帰登録内の親本文保持を検査しました。
- 保存失敗は候補を保持します。世代競合は再照会します。保存済み・再公開失敗は再保存せず、表示から削除対象を除き、再読込を案内します。
- 復元画面は指定したシステム由来だけの抑止を解除します。個人候補を復活させず、不在の辞書が必ず表示されるとも案内しません。
- テキスト書出しは個人辞書だけを対象にし、同じ読取トランザクションで数えた「含まれない非表示指定の件数」を案内します。

## 独立レビューと修正

由来と数値集約、状態機械、Android接続、管理器、表示文言、生成試験を別担当が確認しました。単体試験の取消期待値は、もともとのローマ字保留を含む `にほn` が正しいため、`にほん` の期待値を修正し、保留 `n` 自体も明示検査しました。

SAF E2EはUUID付きの一時システム辞書だけを追加し、X→n、X→y、抑止解除、再変換、元辞書のバイト一致復元を行います。独立レビューで、保存後の表示検査に失敗すると変更フラグが未設定になる復旧上の欠陥を発見しました。保存し得る操作の前にフラグを立て、復旧を証明できない場合はバックアップと復旧情報を残すよう修正しました。
