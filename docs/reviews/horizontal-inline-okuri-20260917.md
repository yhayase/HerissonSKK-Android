# 横並び候補・インライン注釈・送り認識の変更

## 目的と契約

縦に一候補ずつ並ぶ一覧を横幅に応じた最大2段のタイルへ変更し、横長画面の高さを節約します。自動件数は1段、上限指定は最大2段を使い、注釈を小さく淡く表示します。単独候補の注釈は入力欄に表示し、下部の重複情報を除きます。送り開始の子音を小文字で入力した後でも、大文字母音で規則が完成すると送りとして扱います。

## 設計とレビュー

- 一覧の件数は候補選択開始時に固定し、ページ中のラベル対応を維持します。既存の件数設定を保持し、設定画面の固定表示を「上限を指定」へ改めました。
- 注釈はIME所有の小さなウィンドウへ描画し、InputConnectionへ渡す本文には一切追加しません。CursorAnchorInfoの対応がない入力先では注釈の表示を省略します。
- 最初の実装では注釈を未確定本文に追加して終了時に除去しましたが、実IMEの通常入力欄からパスワード欄への切替試験で、旧接続が無効となって除去できず本文に残る問題を検出しました。単体試験と初回レビューでは見落としたライフサイクル境界です。この方式は採用せず、設計担当をAstra/highへ上げて、本文とは独立した表示へ変更しました。
- 独立レビューで送り規則の例外、注釈を本文へ送らない境界とウィンドウの寿命、横幅・高さとページ件数の計算を確認しました。追加の修正対象は見つかりませんでした。表示の座標変換・入力欄の切替・非対応の接続を単体・実IMEの両方で検証します。

- 実端末では非タッチウィンドウがアクセシビリティの一覧に現れないことも検出しました。注釈の範囲だけタッチを受け取れる窓にし、キーボードフォーカスを取らず、範囲外のタッチは入力先へ通します。注釈をタッチした後も入力先のフォーカスとキー操作が保たれることをE2Eで確認します。

- API 26ではページ描画が次の候補へ進んでも、アクセシビリティに前の候補が残る問題を実画面との比較で検出しました。変化のないタイルは維持し、変更時には常に公開される親ビューを発信元としてsubtree変更を通知します。独立レビューで、非公開の子を発信元にすると古いキャッシュが消えないAPI 26の条件も確認しました。試験側のキャッシュ消去は行いません。

- API 35の通常入力試験では、選択中のIMEを上書き導入すると初回だけAndroidがSKKプロセスを開始しない状態を追跡しました。別の有効なIMEへ切り替えてから導入すると、元の厳密な待機条件のまま17件が成功しました。実行器をこの順序に改め、導入失敗・試験失敗でも元の選択と有効状態を復元します。元の選択が不明、または必要な切替先がない場合は変更前に停止します。復元と失敗判定は独立レビューとホスト試験で検証しました。

- 最終API 26表示試験で一度、一覧が開かず候補が確定する失敗がありました。同一APKの再実行では再現しませんでしたが、SAF試験から続けた診断で、注釈座標の開始要求と拒否後の停止要求が各2秒待ち、Space処理が合計4秒停止することを確認しました。座標要求を専用ワーカーへ分離し、最新の要求へ集約します。同じ入力先では監視を使い回し、入力先変更や終了後の応答を破棄します。開始拒否時には停止要求を重ねません。この待機の問題は確定していますが、最初の一覧失敗との因果は直接再現できていません。

- 非同期化の独立レビューではキー処理からの同期問い合わせの排除、要求の集約、旧接続の解除と遅延応答の無視、サービス終了時の非待機を確認しました。[Android 8.0のInputConnectionWrapper](https://raw.githubusercontent.com/aosp-mirror/platform_frameworks_base/android-8.0.0_r1/core/java/com/android/internal/view/InputConnectionWrapper.java) では実行中の要求ごとに別のコールバックを割り当てるため、ワーカーの座標要求と主スレッドの本文照会が応答番号を共有しないことも確認しました。追加の修正対象はありませんでした。

## 検証範囲

コアにKasU／KaSuの検索キー・送り・取消状態とカスタム規則の試験を追加しました。Android単体に注釈座標の変換・表示領域・古い候補・無効な値の検証と、注釈をInputConnectionへ一切送らず旧接続失効後も本文を汚さない試験を追加しました。実Androidビューにも横並びと大文字倍率の試験を追加しました。IME E2Eは未確定・確定後とも注釈なしの本文を厳密比較し、別ウィンドウの注釈表示と候補本文を覆わない位置を確認します。最終の結果とAPKは [作業記録](../work-status.md) に記録します。

実機、Firefox・X・Keepでの注釈表示は未確認です。カーソル座標通知に対応しない入力先では、注釈を省略して候補本文だけを表示します。
