## 初回リリース

物理キーボードとQWERTYスクリーンキーボードの双方で、日常のSKK入力・変換・登録を行える版を公開します。

| 必須範囲 | 到達点 |
| --- | --- |
| 基本機能 | 入力モード、ローマ字、送り、abbrev、接辞、候補・注釈、補完、登録・再帰登録、学習・削除、ローカル辞書管理、バックアップ、入力設定を利用できます |
| 設定UI | 各機能のユーザーにとっての意味と利用目的から、画面構成・情報順序・操作の流れ・用語・操作部品を再設計します。内部設定値をそのまま編集欄へ写しません |
| スクリーンキーボード | QWERTYのローマ字入力とShiftによる変換開始を提供し、候補選択・取消・再帰登録までタッチで完結できます。物理キーボード接続時は文字キー画面を隠せます |
| ネットワーク辞書 | システム辞書をURL指定または著名辞書のリストから導入し、利用者の明示操作で更新できます。定期・起動時の自動更新は行いません。取得後の変換はローカルで完結します |
| 初期辞書 | S辞書を初期設定とします。同梱か初回取得かはサイズとライセンスを確認して決めます |
| アプリ別設定 | ショートカットとの衝突を避けるため、アプリ別にEmacs編集キーを有効／無効にできます |
| IME切り替え | 別のIMEへ物理キーボードとタッチの双方から切り替えられます |
| 候補・登録表示 | 入力欄を隠さず、候補・注釈・再帰登録の階層と操作対象を読み取れます。既存の表示修正だけで全面改善完了とは判定しません |

数値変換は実装済みですが、追加整備・受入を初回の必須条件から外します。既存機能を削除する方針ではありません。

### 公開と品質判定

初回はAPK配布を基本とします。Playストア公開は、その時点の制度・費用・公開条件を確認して再判断し、初回の必須条件にはしません。[配布方針](distribution.md) に確認先を記録します。

利用者が日常利用して支障がない機能・ユーザビリティ、DDSKKやCorvusSKKとの操作上の差異の小ささ、既知の重大な欠陥がないことを品質基準とします。最終的な操作感は利用者が確認し、自動試験と操作例の比較を判断材料にします。意図的な操作差異は理由と制約を記録します。固定したDDSKK参照版は維持し、CorvusSKKの比較版・操作例は検証設計で具体化します。

対象はXiaomi Pad 8とPixel 7の縦横画面、JIS／US配列、画面キーボードです。必須10アプリとシナリオの割り当ては [検証計画](validation-plan.md) に集約します。全組み合わせの総当たりE2Eを要求せず、入力欄の特性とリスクに応じた代表経路を確認します。入力消失、二重確定、誤送信、別入力欄への誤挿入、辞書破損などの重大な欠陥を残して公開しません。

## 初回公開後の優先順位

| 順序 | 対象 |
| --- | --- |
| 公開直後 | バグ修正 |
| 後続1 | 数値変換・日付入力。同じ優先度で整備します。日付の操作列・形式・通常の@との区別は設計時に定義します |
| 後続2 | アプリごとの個別キー割り当て。初回のEmacs編集オン／オフより細かく変更できます |
| 後続3 | 任意の候補ラベル |
| それ以下 | 下記のその他機能。相互の全順序は付けません |

その他機能は、回転・キーボード切断時の変換状態保持、再変換、規則・設定の入出力、辞書サーバー接続、追加DDSKK機能、追加入力方式などです。再変換は確定履歴と選択文字列を別々に評価し、対象範囲が確認できなければ変更しません。既存バッファのQによる取り込みや任意のEmacs Lisp実行の再現とは区別します。

個人辞書同期は順位を保留します。このIMEの端末間同期と他のSKK入力ツールとの共有を区別し、共有できる情報、競合・削除の反映、認証・通信失敗の制約を調べてから意味と優先度を判断します。

設定の入力試行やプレビューは、初回のUI設計に必要なら初回に含めます。独立した後続機能と決めつけません。

## 調査・設計に残す事項

- S辞書の同梱サイズ、取得・再配布条件、初回取得時の操作と失敗時の扱い。
- 著名辞書リストの対象、取得元、ライセンスと手動更新の詳細。
- QWERTYのキー配置、接続変更時の表示、タッチのSKK操作、IME切り替え操作。
- アプリ別Emacs設定の識別・適用範囲と既定値、設定UIの具体的な画面構成。
- 各端末のOS・アプリ版、代表シナリオの配分、比較するCorvusSKKの版と操作例、実測に基づく性能評価。
- 依存コード・辞書の条件を確認し、可能なら非コピーレフトのpermissiveなOSSライセンスを選定します。具体的なライセンスは未決定です。
