## Unicode と配布物

内部編集は ICU4J 77.1／Unicode 16 の書記素境界を使います。ライセンスは `core/src/main/resources/META-INF/icu-LICENSE.txt` に置き、`app` と `test-editor` の APK に同梱します。JVM の公式コーパス 1 件と Android の `CoreUnicodeTest` 2 件は API 26／30／35 で成功しています。これはライブラリの読み込みと代表操作の証拠であり、全端末での容量・性能・Unicode 互換性の受入判定ではありません。

## 未完了の要件と次の試験

K09〜K19、F05、F13、S01〜S08、N04〜N12 は未実装または限定実装を含み、受入済みではありません。特に次を残します。

- 登録、学習、複数・外部辞書、辞書入出力、永続化、保存失敗と再起動。
- 非同期照会の要求番号、待機キー、取消・欄切替後の遅延結果、設定変更の競合検証。
- 未確定外の入力欄編集、候補表示の幅・アクセシビリティ、対象アプリ・物理配列・実機の互換性。
- 性能の受入基準、実機での測定、APK 容量と更新時データ保持。

次は、限定コア辞書を実辞書・非同期ポートへ置き換える前に、各失敗経路と保存境界の試験契約を追加します。結合試験は代表列を保ちつつ、対象アプリと実機・配列を記録して広げます。
