# AZIK プロファイル

## 出典と実装方針

このプロファイルは、木村清による [「AZIK 総合解説書」2025 年 5 月改訂版](https://note.com/actbemu/n/n74f1c04c9a2e) を一次仕様とします。QWERTY 配列で OS の配列変換後に得られる論理文字を対象にし、解説書が示す変換結果を、行と拡張キーの組合せから生成する独立した Kotlin データとして実装しています。出典の文章、表、既存実装のコードは収録していません。

SKK との競合部分は DDSKK 17.2 の固定コミット `e8bf68b27021c29781dbfa6a8ef7b770565bdb5b` の利用者向け動作も確認しました。GPLv3 の規則データは転記せず、`q`、かな切替、小書き母音、追加の特殊拡張、TG/DC の長音について観察した互換動作だけを本プロジェクトの規則構成へ反映しています。

## 規則の範囲

`AzikRules.rules` は変更不能な完全規則一覧、`AzikRules.ruleSet` は一度だけ検証・索引化する `RomanRuleSet` です。標準ローマ字を基礎に、次の分類を一つのプロファイルとして構成します。

- 通常かな: 清音、濁音、半濁音と通常の拗音を従来のローマ字でも入力できます。
- 撥音拡張: 各行の母音を、`z`、`k`、`j`、`d`、`l` に置き換えると、それぞれ「あ段＋ん」から「お段＋ん」になります。左手側の子音では `n` も「あ段＋ん」に使えます。例は `kz` → `かん`、`sk` → `しん`、`wd` → `うぇん` です。
- 二重母音拡張: `q`、`h`、`w`、`p` を使い、「あ段＋い」「う段＋う」「え段＋い」「お段＋う」を入力します。あ行は `ai`、`uu`、`ei`、`ou` の通常入力を維持します。
- 拗音互換: `x` をシャ行、`c` をチャ行に使います。右手側の `y` は `g` でも置き換えられ、`kgp` → `きょう`、`ngz` と `ngn` → `にゃん` になります。拗音にも撥音拡張と二重母音拡張を適用します。
- 同指打鍵互換: `kf` → `き`、`yf` → `ゆ`、`jf` → `じゅ`、`hf` → `ふ`、`mf` → `む`、`nf` → `ぬ`、`df` → `で`、`cf` → `ちぇ`、`pf` → `ぽん` を収録します。
- 特殊拡張: `kt` → `こと`、`mn` → `もの`、`ms` → `ます`、`ds` → `です` などの頻出文字列を収録します。SKK 互換として `mr` → `まる`、`dr` → `である`、`dg` → `だが`、`fr` → `ふる` も収録します。通常の拡張軸と入力が重なる場合は特殊拡張を優先します。
- 外来音: ファ行とヴァ行に加え、それぞれの撥音・二重母音拡張を収録します。一次仕様の `tgi` → `てぃ`、`tgu` → `とぅ`、`dci` → `でぃ`、`dcu` → `どぅ`、`wso` → `うぉ` と、SKK 互換の `tgh` → `てゅー`、`tgp` → `とぅー`、`dch` → `でゅー`、`dcp` → `どぅー` を含みます。
- 専用・互換記号: `;` → `っ`、`q` → `ん`、`:` と `-` → `ー` です。リテラルの `;` は `x;` で入力できます。

AZIK では促音を常に `;` で入力するため、標準プロファイルの子音重ねによる促音は除外します。`shi` と `chi` 系も AZIK の `x` と `c` に置き換えます。一方、競合しない通常ローマ字は残すため、未習得の拡張を従来の入力で補えます。

あ行には撥音拡張と二重母音拡張を適用しません。母音の前に `i` がある `ia`、`ii` なども専用規則ではなく、通常ローマ字を順に処理して `いあ`、`いい` となります。

## SKK コマンドとの境界

AZIK は `q` を規則文字として所有し、単独の `q` は `ん` を生成します。このため、かな切替コマンドは英語 QWERTY の論理文字 `[` へ移します。`[` 自体はコマンド層が先に処理し、リテラルの `[` は `x[` で入力できます。コマンド割当と大文字による読み・送り開始はローマ字規則ではなく、エンジンの状態別コマンド層が担当します。

SKK が `l` を ASCII／全英切替に使う状態では、単独の小書き母音を `xxa`、`xxi`、`xxu`、`xxe`、`xxo` で入力します。小書きの「ゃゅょゎ」は `xya`、`xyu`、`xyo`、`xwa` を使えます。これにより `l` のコマンド所有と AZIK のかな規則を曖昧にしません。

規則層は `q`、`x`、`;`、`:`、`-` と、複数打鍵の途中に現れる `[` や `l` を所有します。コマンド層は直接入力された `[`、状態に応じた先頭の `l`、大文字を所有します。大文字を SKK の読み開始・送り開始として解釈する統合処理、`[` へのかな切替割当、状態ごとのコマンド優先順位はコアエンジン側の責務です。

## 検証例

単体試験では、通常かな、撥音拡張、二重母音拡張、拗音と互換子音、同指打鍵互換、特殊拡張、外来音、専用記号、SKK 用小書き入力、未消化列と終端処理を分類ごとに確認します。一次仕様との固定照合例として `kz` → `かん`、`kgp` → `きょう`、`ngz`／`ngn` → `にゃん`、`:` → `ー` を含めます。
