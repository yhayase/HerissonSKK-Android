## レビューで修正した不具合

- 独自Unicode境界の5件はICU4J77.1への置換と境界再評価で修正し、別担当が元の再現例を検証しました。
- ローマ字終端時の出力・残余の消失、非カナ文字の正規化、規則の不整合を修正し、独立レビューと22件の試験を通しました。
- エンジンの残余よりリテラルが先に確定する問題、取消で残余とカーソルが復元されない問題、途中残余の表示位置、読み先頭での空語幹の送り境界を修正しました。別担当が修正と回帰試験を確認しました。
- 遅延した自分自身の選択通知で最新の座標を巻き戻す問題を修正しました。ガードを外す変異試験でAPI26/35の両方が期待位置4／実際2として失敗し、復元後の全試験が成功しました。
- E2Eの準備待ちが古い「かな」表示へ依存していたため、パッケージと安定したリソースIDで確認する方式へ変更しました。

詳細は[基本変換レビュー](reviews/basic-engine-20260916.md)、[Android接続レビュー](reviews/android-core-adapter-20260916.md)、[ローマ字レビュー](reviews/romanizer-20260916.md)を参照します。

## 学習と中断復旧の追加検証

候補学習は入力先の確定成功後にだけ要求します。保護欄・学習禁止・確定拒否では保存要求を出しません。接続終了後の完了通知は別の入力欄や表示を更新しません。独立レビューの試験不足2件を追加し、Android試験を再実行しました。

入力E2Eの最新成功履歴は `connection/emulator-5582/20260916T034403312084Z` と `connection/emulator-5584/20260916T034411423454Z` です。固定候補の試験欄は標準の学習禁止フラグを指定し、実行順で辞書順位が変わることを防ぎます。通常学習の実IME経路も退避付きSAF試験で成功しました。二番目の候補を選び、書き出しで順位・注釈を検査し、新しい入力セッションで先頭候補になることを確認します。

Native SQLiteは各6件です。`dictionary-instrumentation/emulator-5582/20260916T033939073256Z` と `emulator-5584/20260916T033938592875Z` で、未コミットの行変更後に専用子プロセスを終了し、再接続で旧世代・旧候補を確認しました。debug専用・非公開サービスとUUID名DBを使い、通常DBには触れません。benchmark APKにサービスがないことも確認しました。電源断・全保存タイミングの証拠ではありません。

数値変換は単体12件成功ですが、独立レビューで大字の萬と展開結果の重複を修正し、別担当が確認しました。実IMEへの接続は未完了です。試験数を製品要件の網羅率とは扱いません。
