# 開発の継続記録

更新日: 2026-09-16

## 現在の作業

純Kotlinの基本変換コアをAndroidへ接続し、限定試験辞書で要件から導いた操作列を検証しました。完全な辞書・登録・学習・設定はこれからです。全製品の完成やフェーズ1の実機性能合格は宣言していません。

GitHub は `yhayase/skk-android` のプライベートリポジトリです。開始前の文書を `6510fb5`、計測画面の準備処理を `9b55f32`、Unicode編集を `423240c`、独立レビュー済みローマ字部品を `2b05d46` でpushしました。以後も検証済みの単位でpushします。

## 今回の検証

- コアのJVM試験: 91件成功、失敗・エラー・スキップ0件です。内訳は基本変換26、ローマ字と文字種22、内部編集14、公式Unicode適合1、辞書形式19、複合検索8、生成キー列1です。生成試験は32 seed・計16,000操作を検査します。適合試験はUnicode16の1,093ケースをすべて検査します。
- Android単体試験: 67件成功、失敗・エラー・スキップ0件です。RobolectricのAPI26/35での呼出しを含む数であり、67種類の独立した要件を示す数ではありません。
- Python実行器の試験: 5件成功です。instrumentationの失敗・スキップ・途中終了・件数不整合を成功にしません。
- API26、30、35の各専用エミュレーターで、別アプリからの入力E2E10件とAndroid上のUnicode2件、計12件がすべて成功しました。未実行・スキップを合格へ含めていません。
- IMEのdebug／benchmark、入力確認アプリ、instrumentation APKのビルドが成功しました。LintはIME指摘0件、入力確認アプリはエラー0件・既存警告4件です。

## レビューで修正した不具合

- 独自Unicode境界の5件はICU4J77.1への置換と境界再評価で修正し、別担当が元の再現例を検証しました。
- ローマ字終端時の出力・残余の消失、非カナ文字の正規化、規則の不整合を修正し、独立レビューと22件の試験を通しました。
- エンジンの残余よりリテラルが先に確定する問題、取消で残余とカーソルが復元されない問題、途中残余の表示位置、読み先頭での空語幹の送り境界を修正しました。別担当が修正と回帰試験を確認しました。
- 遅延した自分自身の選択通知で最新の座標を巻き戻す問題を修正しました。ガードを外す変異試験でAPI26/35の両方が期待位置4／実際2として失敗し、復元後の全試験が成功しました。
- E2Eの準備待ちが古い「かな」表示へ依存していたため、パッケージと安定したリソースIDで確認する方式へ変更しました。

詳細は[基本変換レビュー](reviews/basic-engine-20260916.md)、[Android接続レビュー](reviews/android-core-adapter-20260916.md)、[ローマ字レビュー](reviews/romanizer-20260916.md)を参照します。
