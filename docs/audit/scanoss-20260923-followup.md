## ServiceConfigurationTest：何を検証するコードか

検出されたローカル6–26行は、JUnit / Robolectric の import・テスト用注釈と、`passwordVariantsAreProtected` という試験の一部です。試験では、通常・表示可能・Web・数値のパスワード欄を、本 IME の `SkkInputMethodService.isPassword` が正しく判定するか確認します。通常のテキスト欄や URL 入力欄をパスワード扱いしないことも検証します。

ここに並ぶパスワード等の定数はアプリ独自の定義ではなく、[Android の InputType](https://developer.android.com/reference/android/text/InputType) が公開するものです。自動入力アプリと IME の両方がこれらを使うことは自然です。ただし、これが今回のフィンガープリント一致の直接の原因だったという説明は、比較元本文を取得していないため推定です。

追加調査では公開リポジトリの記録と GitHub イベントアーカイブから過去のコミット識別子までたどりましたが、該当 `StructureParser.kt` の本文は回収できませんでした。過去のリポジトリ情報やタグ一覧は、本体ソースを取得できたことの代わりにはなりません。
