HerissonSKK (for Android)

プライバシーポリシー

制定・最終更新日: 2026-09-23

Yasuhiro Hayase（以下「作者」）は、日本語入力アプリ HerissonSKK (for Android)（以下「本アプリ」）を提供します。本ポリシーは、本アプリとこの案内サイトにおける情報の取扱いを説明します。

入力内容と学習データ

本アプリは、文字変換と編集のため、入力中の文字、読み、候補、入力欄の周辺テキストを端末内で処理します。通常の入力欄では、変換候補の学習結果、登録した単語、読み、確定した文字列、候補の利用順などをアプリ専用の端末内ストレージに保存することがあります。「変換結果を学習する」を無効にすると、以後の入力から単語登録や候補の使用履歴を保存しません。この設定を変更しても、すでに保存されたデータは削除されません。

パスワード欄として通知された入力欄では、変換、候補表示、登録、学習を無効にします。入力先アプリがパーソナライズ学習を禁止した場合も、学習データを保存しません。本アプリは、入力内容や個人辞書を辞書配布サーバーへ送信しません。

アプリ別設定

アプリ別の編集キー設定を表示するため、端末上で起動可能なアプリの表示名とパッケージ名を読み取ります。一覧全体は保存せず、利用者が個別設定を行ったアプリのパッケージ名だけを端末内に保存します。この情報はネットワークへ送信しません。

クリップボード

Emacs 編集の kill-line 機能を使うと、削除したテキストを端末のクリップボードへ書き込みます。連続した kill 操作では、本アプリがその入力セッションで書き込んだ内容かを確認するため、クリップボードを読み取ります。一般的なクリップボード履歴を収集する機能はありません。クリップボードは OS の共有領域であり、端末の設定や他のアプリから見える場合があります。

辞書のダウンロードと通信情報

初期設定では、SKK-JISYO.S と SKK-JISYO.L のどちらも保存されていない場合に、SKK-JISYO.S を GitHub 上の配布元から自動的にダウンロードします。また、利用者の操作により、辞書の追加・更新、GitHub 上の配布元からの取得、または利用者が指定した公開 HTTPS URL からの取得を行います。転送先が設定されている場合は、その転送先にも接続します。

配布サーバーと転送先には、IP アドレス、接続日時、要求先のホストやパス、通信方式、固定のアプリ識別文字列などの通信情報が伝わり、各事業者の方針に従って記録される場合があります。S／L／jinmei／geo 辞書の配布に使う GitHub Pages は、訪問者の IP アドレスをセキュリティ目的でログ記録・保存すると説明しています（GitHub Pages のデータ収集説明）。DNS の名前解決では、DNS 事業者に問い合わせ先のホスト名などが伝わる場合があります。本アプリは、辞書取得の要求に入力内容、個人辞書、端末固有 ID、アプリ一覧を付加しません。固定のアプリ識別文字列 skk-android/1 はインストール ID ではありません。利用者が指定したサーバーの運用方針は作者が管理できません。

辞書ファイルとバックアップ

辞書の読込み、個人辞書の書出し、完全辞書バックアップでは、Android のファイル選択画面を使用します。利用者がクラウドストレージなどの文書プロバイダーを選ぶと、その事業者へファイルが渡り、事業者のプライバシーポリシーが適用されます。

書き出す辞書と完全バックアップは暗号化されません。完全バックアップには、個人辞書、追加辞書、学習履歴、候補の非表示指定、辞書の取得元 URL などが含まれます。機密情報として扱い、保存先と共有先を利用者自身で管理してください。本アプリは、アプリ内データが Android の自動クラウドバックアップと端末間転送の対象外になるよう設定しています。

保存期間と削除

学習データ、辞書、設定は、利用者が削除するまで端末内の本アプリ用ストレージに保存されます。Android の設定から本アプリのストレージを消去するか、本アプリをアンインストールすると、端末内のアプリデータを削除できます。利用者が書き出した辞書、バックアップ、クリップボードの内容、文書プロバイダーに保存した複製は自動では削除されません。それぞれの保存先で削除してください。

案内サイト

この案内サイトは GitHub Pages で配信します。サイト自体には、アクセス解析、広告、外部フォント、外部 JavaScript を組み込んでいません。GitHub はサイト配信のため、IP アドレス、ブラウザー情報、アクセス日時などを処理する場合があります。詳しくは GitHub のプライバシーに関する声明を確認してください。

本ポリシーの変更

本アプリの機能、配布方法、関係するサービスの変更に応じて、本ポリシーを改定することがあります。改定した場合は、このページに内容と最終更新日を掲載します。
