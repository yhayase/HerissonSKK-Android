# 再帰登録の入力 UI

登録本文を一つの入力欄として扱う表示契約です。

## 表示

登録する読みは見出し「単語登録：○○」で一度だけ示します。主領域は登録する文字列とカーソルです。確定済みの本文のカーソル位置に、未確定の読みまたは変換候補を挿入して表示します。本文・読み・候補を別行に分離しません。

物理キーボードではアプリ入力欄と同様に、変換中の候補を入力欄内へ表示します。候補一覧は既存のインライン候補数を越えたときだけ表示し、インライン候補を一覧へ重複させません。候補一覧は登録入力欄の近くに置きます。モード表示は入力カーソル付近に短時間だけ表示します。

画面キーボードでは登録欄にも読みを表示し、候補はキーボード上のタッチ可能な一覧で選びます。物理入力用のインライン候補を混在させません。

再帰しても窓を重ねず、同じ登録領域を現在の登録へ切り替えます。子の登録中だけ親の読みを小さく添えます。階層番号・階層全体・「操作対象」の重複表示はしません。子の登録結果は親のカーソル位置に入り、親の編集を再開します。

本文は途中で省略せず、折り返しとスクロールで扱います。入力中のカーソルが見える位置を保ちます。常設の操作説明や通常の辞書状態通知を登録本文へ混在させません。保存中・失敗など、今の操作に必要な状態だけを表示します。

## 操作

読み入力・送り・変換・候補選択・確定・取消は既存の共通入力エンジンを使います。物理入力と画面入力の違いも、アプリ本文と同じ規則です。登録への入出と保存だけが登録画面固有です。未確定入力が残る間は登録ボタンで別の意味の確定を行わず、通常の入力操作で確定してから登録します。

登録画面がアプリの入力フォーカスを奪うことはありません。文字列を表示する標準ウィジェットを使い、IME が所有する編集状態に必要なカーソル・未確定範囲の表示を補います。表示用の独立したテキストバッファを第二の入力先として作りません。

未確定入力がないときは本文のタップでカーソルを移動できます。未確定入力中のタップで勝手に確定せず、カーソル編集には通常のキー操作を使います。スクロール操作をタップとして扱いません。物理入力の動的補完は入力位置に薄い斜体の補完部分として示し、確定本文へ混入させません。

保存中は登録・取消ボタンを無効にします。物理 C-g による保存待機の取消は既存の動作を維持し、遅れて完了した保存結果が別の入力先へ挿入されることを防ぎます。本文が長い場合の表示高は 160dp と画面高の25%の小さい方を上限とし、全文をスクロールして表示します。

## 検証範囲

確定本文の途中での読み・候補の置換、候補の確定と取消、親子間の復帰、物理／画面入力の違い、長文・折り返し・カーソル追従、保存中・失敗、古い表示の操作が別の登録を変更しないことを確認します。
