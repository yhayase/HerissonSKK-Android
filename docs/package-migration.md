# 試用版から se.haya.skk への移行

所有ドメイン `haya.se` に合わせ、コードの基底パッケージ、Androidの `namespace` と `applicationId` を `se.haya.skk` に統一します。測定版は `se.haya.skk.benchmark`、専用入力テストアプリは `se.haya.skk.testeditor` です。

旧試用版の `jp.hayase.skk` とはAndroid上で別アプリです。上書き更新やアプリ内データの自動引継ぎは行われません。移行確認が済むまでは旧試用版をアンインストールしません。

## 辞書の移行手順

1. 旧試用版の設定から「完全辞書バックアップを保存」を実行し、端末内の分かる場所へ保存します。
2. 新版をインストールして入力方法を有効にします。両方が同じ表示名の場合は、Androidのアプリ情報でパッケージを確認します。
3. 新版の「完全辞書バックアップから復元」で保存したファイルを選び、辞書件数・候補数を確認して適用します。復元先の辞書全体を置き換えるため、移行先で先に作成した辞書がある場合はそちらも退避します。
4. 新版を入力方法として選択し、システム辞書の語と個人登録語を変換できることを確認します。
5. 移行できたことを確認してから、旧試用版の無効化・削除を判断します。

完全バックアップの形式識別子と版は、パッケージ名の変更では変更しません。個人辞書、システム辞書、有効状態・優先順、候補の非表示指定を移します。入力設定、キー割当、アプリ別Emacs設定、Android側のIME選択はバックアップ対象ではなく、新版で設定し直します。

これは初回公開前の識別子変更です。今後公開したアプリの更新では、アプリIDと署名の継続性を維持します。
