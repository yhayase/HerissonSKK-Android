## 基準と設定

- 基準は DDSKK 17.1、コミット `8c47f46e38a29a0f3eabcd524268d20573102467` とします。[固定したソース](https://github.com/skk-dev/ddskk/tree/8c47f46e38a29a0f3eabcd524268d20573102467)。ローカルの `/home/hayase/tmp/ddskk` の追跡対象ファイルを参照しました。未追跡の `utf/` は基準に含めません。
- 標準のローマ字規則を基準とし、個人の `.skk` は読み込みません。通常学習と数値変換は有効、動的補完は初期状態では無効にします。ネットワーク辞書は無効にします。
- Enter は未確定入力があれば確定だけに使います。DDSKK の `skk-egg-like-newline = t` に相当する方針です。未確定入力がない Enter は入力先へ渡します。
- 最初の 3 候補は単独表示し、それ以降は `a s d f j k l` の 7 ラベルで一覧表示します。この表示設定は本製品の初期値です。
- 新しい入力セッションはひらがなで開始し、パスワード欄は直接入力で開始します。アプリをまたいだモード記憶は初期仕様に含めません。
- DDSKK と異なる Android 向けの選択は本書を優先します。DDSKK 実行との自動差分検証は未実施です。

## 状態と共通操作

`C-j` は Ctrl+j、`C-g` は Ctrl+g、`SPC` は Space、`BS` は Backspace です。大文字は Shift 付き入力を表します。`▽` と `▼` は状態の説明記号で、確定文字には含めません。

| 状態 | Enter | C-j | C-g | BS |
| --- | --- | --- | --- | --- |
| ASCII、未確定なし | 入力先へ渡します | ひらがなに切り替えます | 入力先へ渡します | 入力先へ渡します |
| かな、未確定なし | 入力先へ渡します | ひらがなにします | 消去対象なしとして消費します | 入力先へ渡します |
| 未消化ローマ字 | `n` は `ん`、他は規則上の確定結果または残余文字として確定します。改行しません | 同様に確定しひらがなにします | 未消化部分を捨てます | 未消化部分を一文字削除します |
| 見出し語・abbrev | 読みを確定します。改行しません | 読みを確定しひらがなにします | 見出し語を取り消します | 未消化部分を先に削除し、次に読みを削除します。空の見出し語でさらに BS を押すと通常状態へ戻ります |
| 候補・候補一覧 | 候補を一度だけ確定します | 候補を確定しひらがなにします | 読みを保持して見出し語へ戻ります | 前候補へ戻ります。先頭では見出し語へ戻ります |
| 削除確認 | 確認の明示的な肯定操作だけで削除します | 削除しません | 候補表示へ戻ります | 削除しません |

候補選択に使わない通常文字は、候補確定後に新しい入力として一度だけ処理します。Escape は未確定・登録中では C-g 相当、通常状態では入力先へ渡します。未割り当ての Ctrl／Alt ショートカットは渡します。ただし AltGr などによる文字生成は先に判別し、ショートカットとして一律に除外しません。文字とキー割り当ては OS の選択レイアウトに従います（[レイアウトの責務](validation-plan.md)）。半角カナ切替の初期キー、削除確認の肯定キー、補完巡回キーの詳細は設定仕様を作るフェーズ 4 までに決めます（削除確認はフェーズ 3 実装前）。

## 登録の状態遷移

1. 候補なし、または候補を使い切った場合は、戻り先（読み、候補位置、ページ）を保持して登録へ入ります。
2. 登録内に未確定文字がある Enter は登録内での確定だけを行います。次の Enter で非空の登録文字を保存します。送りありは語幹を保存し、入力先へは送りを付けます。
3. 登録内に未確定文字がない C-j は何もしません。空の登録で BS も何もしません。
4. C-g は登録内の候補→見出し語、見出し語→消去、未消化ローマ字→消去の順で内側を取り消します。内側に未確定がなければ登録を一段だけ中止します。最上位では通常入力へ戻します。
5. 空の登録で Enter は保存せず、保持した直前の読み・候補・ページへ戻します。
6. 子の登録完了は親の登録文字だけへ反映します。親を取り消しても、明示的に保存済みの子の辞書項目は残します。
