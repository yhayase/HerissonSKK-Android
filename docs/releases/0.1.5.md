# HerissonSKK 0.1.5

2026年11月25日のGitHubリリース記録です。公開ソースはタグ `v0.1.5` で固定し、署名済みのrelease APKと `SHA256SUMS` を添付します。

## 主な変更

- 広い画面のQWERTYに左右分割を追加します。中央の三角で間隔を調整でき、最下段は間隔を変えても固定です。左右の空白／変換キーを端から届きやすい位置まで広げます。
- 広幅QWERTYは左右にShiftを置き、`M` の右にコンマとピリオド、右上にBackspaceを配置します。カーソルキーは長押しでリピートし、本文の選択中はAndroidの標準矢印キーイベントを入力先へ送ります。
- QWERTYと10キーの高さ・幅・左右位置・下の余白を縦向きと横向きで別々に保存します。QWERTYの分割状態と中央の間隔も向き別です。既存の値は両方の向きに引き継ぎます。
- キー領域の高さは両配列で100 dpから、10キーの幅は10%から設定できます。10キーを片側に寄せているときは、キー領域の隣の矢印で左右位置を反転できます。
- 画面キーボードの候補欄は、利用できる幅と文字サイズに応じて1段または2段に切り替わります。
