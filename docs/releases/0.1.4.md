# HerissonSKK 0.1.4

2026年11月15日のGitHubリリース記録です。公開ソースはタグ `v0.1.4` で固定し、署名済みrelease APKを添付します。Google Playへの提出・公開は含めません。

## 主な変更

- 画面キーボード設定を、配列ごとの画面から目的別の画面へ分けます。配列に依存しない設定を、どの配列を使う場合も見つけやすくします。
- 候補表示領域を固定し、単語登録をモーダル画面に分けます。長い候補本文は領域内で折り返してスクロールでき、登録操作は固定フッターから行えます。
- 入力欄の準備前に届いた画面キーボード表示要求を保持し、入力欄の準備後に表示できるようにします。
- 標準ローマ字の拡張かな・撥音規則、大文字入力時の読み開始と送り境界、および物理キーで撥音を入力した後のモード切替を修正します。
