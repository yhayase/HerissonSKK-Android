# HerissonSKK 0.1.1

2026年10月25日のソースリリースです。公開対象のソースはタグ `v0.1.1` で固定します。GitHub が生成するソースアーカイブを提供し、APK／AAB は添付しません。Google Play への提出・公開はこのリリースに含めません。

## 主な変更

- かな・英字・数字の10キー配列を追加しました。ひらがな／カタカナ、英字・数字の半角／全角、記号・絵文字パレットを使用できます。ホールドによる読み・送り境界と、方向の往復による濁音・半濁音・小書きなどの修飾に対応します。
- 「⇧」の長押しで、現在の面の自動見出し語モードを切り替えられます。かな・英字・数字ごとに状態を保存し、短押しでは読み開始・送り境界を指定します。ホールド時間は100〜1000 msを10 ms刻みで調整できます。
- 配列切替キーのタップでQWERTYと10キーを切り替え、右フリックの地球儀でIME切替、さらに右の歯車で設定画面を開けます。10キーでは上フリックで高さ・幅・左右位置・下の余白を調整できます。これらの配列切替・形状調整では編集中の読み・送り・候補・登録を保持します。
- 10キーの初期面を入力欄に合わせ、文字のパスワード欄は半角英字、数字欄とPIN欄は半角数字で開始します。通常欄へ戻ると元の面・文字種を復元します。保護欄では変換・学習を行わず直接入力します。
- QWERTYと10キーのフリック開始を24 dp以上、中央復帰を16 dp以内にそろえ、キーを小さくしても判定が過敏にならないようにしました。離す瞬間の座標だけでは新しいフリックを認めず、始点から250 dp以上離れた操作を取り消します。IMEウィンドウ外へ伸ばす操作でも元の移動座標を扱い、ホールド成立後の小さな指の揺れを許容します。
- 候補本文と注釈を分け、画面キーボードでは候補の長押しで注釈をポップアップ表示します。夜間表示、候補・ガイドの配置、画面下のOS操作領域との余白を調整しました。削除キーの長押しによる連続削除と、入力先の現在の選択範囲に対する削除にも対応します。
- DDSKK辞書の取り込み・書き出しで、区分・見出し順・個人注釈・候補内の改行を保持し、EUC-JIS-2004に対応しました。既知の非対応形式は取り込み前に警告します。
- かな入力の待機中に `@` から今日の日付を選べます。元号・西暦・ISO形式と限定した日付式に対応し、選んだ形式を学習しても日付は検索ごとに更新します。任意のLisp式は実行しません。

操作の詳細は[利用手順](../usage.md)、距離判定は[フリック判定の設計](../flick-gesture-design.md)、日付式の範囲は[日付入力仕様](../date-input-design.md)を参照してください。

## データの互換性

SQLiteは版7、完全バックアップの書き出しは版5です。旧版DBを移行し、完全バックアップ版1〜4を読み込めます。版5のバックアップは版4以前だけに対応するアプリでは復元できません。形式と移行時の扱いは[完全バックアップ設計](../complete-backup-design.md)を参照してください。
