# HerissonSKK 0.1.3

2026年10月31日のGitHubリリース記録です。0.1.2で初回公開した10キー入力の初期実装を完了し、入力中の予測更新、送信ラベル、アイコン表示を改善します。公開ソースはタグ `v0.1.3` で固定し、署名済みrelease APKを添付します。Google Playへの提出・公開は含めません。

## 主な変更

- 読みの変更で不要になった実行中の予測検索を、SQLiteの処理も含めて中止します。従来の古い結果の反映防止に加え、新しい読みの検索が古い検索の終了を待つ時間を減らします。
- 画面の予測候補を、初期表示の16件から必要に応じて最大64件まで段階的に広げます。追加候補でも、既存の候補順位を保ちます。
- Enterでアクションを実行しない指定（`NO_ENTER_ACTION`）の入力欄では、「送信」ではなく「⏎」を表示します。
- 送信は紙飛行機、検索は虫眼鏡の単色アイコンで表示し、キー文字と同じ色にそろえます。

10キー入力の初回公開は0.1.2です。本版では予測更新と候補拡張の修正を含め、10キー入力の初期実装を完了とします。端末ごとの操作感、誤入力、ガイド、振動の評価は継続します。
