# アプリ別 Emacs 編集設定の設計

F13・F22・S02 に従い、Emacs 編集キーだけをアプリごとに全体設定から上書きします。全体設定は「無効」「IME 内のみ」「IME とアプリ」の三択で、初期値は「無効」です。アプリ別の指定がなければ全体設定を継承し、指定があれば IME 内を含む範囲全体を置き換えます。キー割り当て、SKK コマンド、保護入力の例外、内部バッファ編集の契約は変更しません。

## 識別と適用

IME は入力セッション開始時に `EditorInfo.packageName` とその時点の全体設定を渡して `AppEmacsEditingStore.emacsEditingMode(packageName, globalMode)` を一度評価します。結果はその入力セッションの `EditorSession` に固定します。設定変更は入力中のセッションを変更せず、次の入力欄から反映します。

入力に使う値は保存成功が確認された値だけです。保存中の選択は画面に表示しますが、新しい入力欄にも未保存の値を渡しません。画面では全体設定・標準値・選択中アプリの保存済みの適用範囲を表示します。

全体でEmacs編集を無効にしている間に、編集キーとSKK操作の重複が設定されている場合があります。アプリ別の有効化時には現在のキー・規則との整合性を検証し、競合があれば保存せず設定変更を案内します。後から全体のキー設定が変わった場合も入力開始時に検証し、競合した入力欄ではEmacs編集を停止して理由を表示します。保存済みのアプリ別指定を勝手に消さず、キーを修正した次の入力欄で再び適用します。通常の状態表示を無効にしていても競合の案内は表示します。

パッケージ名は Android の通常のドット区切り識別子（3〜255文字、各要素は英字で始まり英数字または `_`）だけを保存します。IME が受け取った値が空・不正・未取得なら例外にせず全体設定を継承します。保存された不正値は無視します。有効と無効が同じパッケージへ重複した旧データでは有効を優先し、次の明示保存で正規化します。

## 保存と画面

設定は専用の `SharedPreferences` に、三つの適用範囲ごとのパッケージ集合として保存します。書込みは一つの直列ワーカーで `commit()` し、失敗時は直前の集合を再保存してメモリー表示も直前の値へ戻します。保留・成功・失敗を `AppEmacsEditingState` として公開し、画面の回転後も同じ状態を表示します。失敗時は再試行を表示し、失敗した適用範囲・継承の指定を再送します。

設定画面は `ACTION_MAIN` と `CATEGORY_LAUNCHER` の照会結果からアプリ名とパッケージ名を表示します。既に指定されたが現在はインストールされていないアプリも、パッケージ名と「現在は一覧にありません」の表示で残します。手入力は提供しません。スピナーの初期選択・画面再描画では保存要求を発行せず、利用者が「全体設定に従う」「無効」「IME 内のみ」「IME とアプリ」を選んだ時だけ保存します。


## 旧設定からの移行

全体設定では、旧「入力先」がオンなら「IME とアプリ」、旧「未確定入力だけ」だけがオンなら「IME 内のみ」、両方オフなら「無効」と解釈します。既存の JSON 形式は読み込めます。

アプリ別の旧有効指定は「IME とアプリ」へ移行します。旧無効指定は、移行前の全体設定で IME 内だけの編集が有効なら「IME 内のみ」、そうでなければ「無効」へ移行し、それまでの動作を保ちます。全体設定を変更する前にも移行を行い、旧フラグの意味を新しい選択で失わないようにします。移行後は、各アプリの明示指定が全体設定の変更に影響されず保持されます。
