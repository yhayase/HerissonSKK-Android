# リリース受入条件

本書は候補版を公開する際に適用する判定条件と、変更範囲に応じて選ぶ手動確認例を示します。実施済みの試験、例外判断、成果物のハッシュは対象版のリリース記録に残します。署名・申告・提出の操作は[配布手順](distribution.md)を参照します。

## 判定条件

候補成果物の commit、dirty 状態、APK／AAB の SHA-256、version、署名証明書と、関連する自動検証結果・未確認範囲を特定します。変更した契約に対応する試験が成功し、既知の入力消失、二重確定、意図しない送信、別欄への挿入、個人辞書の破損を残しません。辞書・依存物・アイコンのライセンスと通知、プライバシー申告、公開署名、ストアの提出物を[ライセンス](licenses.md)、[監査資料](audit/README.md)、[配布手順](distribution.md)に照らして確認します。一般公開は公開担当者の最終判断を要します。

人間の操作感と Xiaomi Pad 8 での物理キー・性能の受入を既に得ています。Pixel 7 での重複確認、実メッセージ送信、会話・チャンネル切替、既に確認されたブラウザーのアドレス欄、入力 UI・アプリ別 Emacs・IME 切替の実機反復は、変更による影響や新たな懸念がない限り必須にしません。これは過去の空欄を合格と読み替える意味ではありません。既存の利用者受入とエミュレーター試験の範囲を採用する判断です。

## 記録する条件

手動確認を行うときは同じ候補成果物、端末・OS、アプリ版、辞書の出所とハッシュ、入力方式、配列、期待結果、実結果、未確認範囲を記録します。入力本文・候補・パスワード・認証情報を診断記録へ残さず、画像を残す場合は試験用の無害な文字列とアカウントを使います。

## 変更範囲に応じた入力例

全組合せの総当たりは行いません。必要な変更がある場合、下表から影響する入力欄・端末・配列を選びます。既に受け入れた操作の全件再実施を条件にしません。各行の「入力」は、そのアプリの指定欄を空にしてから行います。物理キーの`Nihon SPC C-j`は、最初の`N`だけをShift+nで入力し、続く`ihon`、Space、C-jを順に押す操作です。最後のC-jは改行せず候補を確定します。画面QWERTYでは`Shift → n → i → h → o → n → 空白/変換 → 先頭候補をタップ`とし、候補タップ自体が確定します。`C-g`は物理キーボードのCtrl+g、`C-j`はCtrl+jです。

共通期待結果は、(1) 大文字で始めた読みが未確定のかなとして表示される、(2) Spaceで候補表示へ入り、物理キーのC-jまたはタッチで選んだ候補が一度だけその欄へ確定する、(3) C-jでは入力先のEnterを実行せず、Enterは既定で候補確定後にも入力先の改行／アクションを一度実行する（確定だけの設定では抑止する）、(4) 読み表示中の取消は一回で読みを除去し、候補表示中は一回目の取消で読みへ戻り、二回目で読みを除去する、(5) 取消した未確定文字と候補が別欄や別アプリへ入らない、です。候補本文は辞書に依存するため一致対象にせず、表示・確定回数・入力先だけを判定します。

## 追加の境界

- 物理JISとUSで、英字、`Shift`、Caps Lock、記号、AltGrまたはデッドキーを通常入力し、US固有の物理位置へ依存しないことを確認します。Bluetooth接続と切断の各後に、画面QWERTYの表示と入力が正しいことを確認します。
- 画面QWERTYだけで、変換開始、候補選択、取消、候補なし語の再帰登録、IME切替を完結します。候補・注釈・登録表示を縦横と大きな文字で読み、入力欄を隠さず操作できるかを「可／不可」と理由で記録します。
- テスト専用の通常欄、パスワード欄、学習禁止欄で`C-j`、大文字、空白、登録キーを試します。パスワード欄ではSKK候補を表示せず直接入力となり、記録にパスワード本文がないことを確認します。学習禁止欄では変換できても辞書順位が変わらないことを確認します。
- 辞書をURLまたはリストから導入し、手動更新を一度実行します。更新中断または失敗後に旧辞書で変換でき、成功表示にならず、自動更新が起きず、オフラインで変換できることを確認します。初期S辞書の自動導入は初期設定から確認します。導入元、ライセンス表示、辞書ハッシュ、失敗方法を記録します。
- 個人語を登録して再起動後に検索し、バックアップ作成・復元をテスト用辞書だけで行います。更新、回転、IME切替、入力欄切替の直後にも、古い候補を再送せず登録文字を別欄へ流さないことを確認します。


実アプリの挙動や OS が変更された場合は、入力先切替、回転、キーボード接続変更、保護欄と学習禁止欄、辞書更新失敗と旧辞書保持、バックアップの復元を影響範囲に応じて選びます。端末に接続して実行できる起動・打鍵測定は[性能測定](performance.md)、辞書測定は[辞書性能測定](dictionary-performance.md)を使います。合成入力の測定値を実 Bluetooth 打鍵や操作感の代替にはしません。
