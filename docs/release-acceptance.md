全組合せの総当たりは行いません。下表で Xiaomi Pad 8／Pixel 7 の縦横、JIS／US、画面QWERTYを一巡させます。各行の「入力」は、そのアプリの指定欄を空にしてから行います。物理キーの`Nihon SPC C-j`は、最初の`N`だけをShift+nで入力し、続く`ihon`、Space、C-jを順に押す操作です。最後のC-jは改行せず候補を確定します。画面QWERTYでは`Shift → n → i → h → o → n → 空白/変換 → 先頭候補をタップ`とし、候補タップ自体が確定します。`C-g`は物理キーボードのCtrl+g、`C-j`はCtrl+jです。

## 当初の接続・辞書・表示の最小手動確認（履歴）

以下は当初の10アプリ受入と合わせて作成した手順です。利用者が受け入れた操作感・性能・実キーボード操作を再確認する現在の作業ではありません。辞書の取得元・ライセンス表示だけは別途進行中の最終監査で扱います。

- 物理JISとUSで、英字、`Shift`、Caps Lock、記号、AltGrまたはデッドキーを通常入力し、US固有の物理位置へ依存しないことを確認します。Bluetooth接続と切断の各後に、画面QWERTYの表示と入力が正しいことを確認します。
- 画面QWERTYだけで、変換開始、候補選択、取消、候補なし語の再帰登録、IME切替を完結します。候補・注釈・登録表示を縦横と大きな文字で読み、入力欄を隠さず操作できるかを「可／不可」と理由で記録します。
- テスト専用の通常欄、パスワード欄、学習禁止欄で`C-j`、大文字、空白、登録キーを試します。パスワード欄ではSKK候補を表示せず直接入力となり、記録にパスワード本文がないことを確認します。学習禁止欄では変換できても辞書順位が変わらないことを確認します。
- 辞書をURLまたはリストから導入し、手動更新を一度実行します。更新中断または失敗後に旧辞書で変換でき、成功表示にならず、自動更新が起きず、オフラインで変換できることを確認します。初期S辞書は公式配布元からの明示取得として同じ経路で確認します。導入元、ライセンス表示、辞書ハッシュ、失敗方法を記録します。
- 個人語を登録して再起動後に検索し、バックアップ作成・復元をテスト用辞書だけで行います。更新、回転、IME切替、入力欄切替の直後にも、古い候補を再送せず登録文字を別欄へ流さないことを確認します。

## CorvusSKKとの将来比較

比較版は **CorvusSKK 3.3.4** に固定します。2026-09-20に公式GitHubの[3.3.4リリース](https://github.com/nathancorvussolis/corvusskk/releases/tag/3.3.4)と[公式リポジトリ](https://github.com/nathancorvussolis/corvusskk)を参照しました。リリースはWindows 10 1607以降／Windows 11向けの`.exe`を示しており、Android版ではありません。比較対象を将来の最新版へ自動更新しません。

Windows環境を用意できるときだけ、同一のテスト辞書・初期設定・キーボード配列で次を両製品へ入力し、各段階の未確定表示、候補表示、確定文字、入力先へ渡ったEnter、取消後の本文を記録します。

| C02 | `Nihon SPC SPC x C-g C-g` | Spaceで次候補、xで前候補へ移る。一回目のC-gで候補から読みへ戻り、二回目で読みが消え、未確定文字と候補が残らない | CorvusSKKの候補順と各取消後の本文 |
| C03 | 候補なしのテスト読み → 変換開始 → 再帰登録 → 登録語入力 → 確定 | 登録語は入力先本文と混ざらず、次の同じ読みで候補になる | CorvusSKKの登録画面・次回候補 |

辞書の候補本文・初期設定・Windowsのアプリと版・配列・記録媒体は実施時に固定し、空欄へ記録します: `辞書hash ____ / Windows版 ____ / 入力先 ____ / 実施日 ____ / 証跡 ____`。この文書作成時点ではWindowsでのインストール、操作、差分判定を実行していません。したがって、上記は比較手順の固定であり、CorvusSKKの挙動や互換性の合格を示しません。
