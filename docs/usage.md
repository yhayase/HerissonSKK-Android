# 利用手順

HerissonSKK を端末へ導入し、物理キーボードまたは画面キーボードで入力する方法を説明します。Google Play での配布はまだ始まっていません。ソースから APK を作成する場合は[開発ガイド](development.md)を参照してください。

## 手元の端末への導入

```sh
adb devices -l
adb -s <端末シリアル> install -r app/build/outputs/apk/debug/app-debug.apk
```

端末で「HerissonSKK (for Android)」を開くと、専用の初期設定が開きます。「入力方法を有効にする」から有効化し、必要な追加辞書を選び、入力方法を選択します。基本のS辞書は初回に自動で準備します。L・人名・地名・郵便番号は選択したものだけを導入します。通信できない場合は再試行するか、後から辞書管理でファイルを導入できます。初期設定は通常の設定画面の最下部から再度開けます。

QWERTYと10キーの両方で、OSのIME切替・非表示ボタンと重ならないよう、文字キーの下に最低48 dpの余白を確保します。OSがそれより大きい下部領域を通知した場合は、その大きさに合わせます。文字キーを隠した場合は、この余白もなくします。10キーでは、この安全用余白の上に「下の余白」を0〜160 dp追加できます。初期値は0 dpです。

スクリーンキーボードは入力欄に対するAndroidやアプリの表示要求で開きます。戻る操作で隠した後は、候補更新や通知領域の開閉だけでは再表示しません。もう一度入力欄をタップすると開けます。[表示条件](keyboard-visibility.md)を参照します。

物理キーボードがない場合は画面下に選択した配列を表示し、読みや候補などがあるときだけ必要な高さの候補領域を表示します。何も表示する内容がないときは、候補行の高さを残しません。初期配列はQWERTYです。Shiftは同時押しのほか、一度タップして次の英字だけを大文字にできます。もう一度タップすると解除します。英字の上フリックも大文字です。下フリックは数字・主要記号、`,`と`.`の上フリックは`!`と`?`です。長押しするとフリックのガイドが出ます。`-`は独立したキーです。`123`で記号面へ移り、`記号1`・`記号2`で面を切り替え、`ABC`で戻ります。[全配列](input-ui-design.md)を参照します。

QWERTYと10キーの削除キーは、タップで一回削除します。押し続けると400 ms後から60 ms間隔で連続削除し、指を離すか操作を取り消すと止まります。入力欄の変更や文字キーの非表示でも停止します。夜間モードでは灰色の文字キー、さらに暗い機能キー、明るい灰色の文字へ切り替わります。

## 10キーを使う（試作）

設定の「入力」→「画面キーボード」で「配列」を「10キー」に変更し、「保存」を押します。次の入力欄から反映します。操作は「通常タップ・フリック」「ホールドで境界」「ホールド＋往復」から選べます。初期値は「ホールド＋往復」、ホールド判定は350 msです。250 ms・500 msも選べます。境界指定の振動はオン／オフを設定でき、端末の触覚フィードバック設定にも従います。

「🌐」を長押しすると、高さ・幅・左右位置・下の余白のスライダーを表示します。変更は即時に反映・保存され、「調整を閉じる」でスライダーを隠せます。長押しで調整やメニューを開くキーは、下部に薄い「…」を表示します。調整モードの「標準に戻す」は形状だけを戻します。初期の高さは256 dpで、キー間の空白はありません。高さの変更では下端を固定して上側を伸縮します。追加する下の余白は0〜160 dpです。幅を狭めると左右へ寄せられます。調整だけでは読み・候補・登録を確定しません。

左上のキーは切替先の「ABC」「123」「かな」を表示し、かな→ABC→123→かなと面を切り替えます。その下の文字種キーは、かなのひらがな／カタカナ、英字と数字の半角／全角を切り替えます。文字種キーにも切替先の「ア／あ」「全Ａ／A」「全１／1」を表示します。面ごとに選択を保持し、切替だけでは入力中の読み・候補・登録を確定しません。全角英字面では、空白キーも全角空白（U+3000）を入力します。読みや候補がある場合は、空白の入力ではなく変換を行います。

「記号」は7分類のパレットです。分類を横へ、文字を縦へスクロールし、ASCII記号、日本語の記号、括弧、矢印、数式、155種類の絵文字を選べます。旗や結合絵文字も分割せず入力します。選択後も開いたままで連続入力でき、「閉じる」で戻ります。面・文字種・読みを切り替えません。用途別の固定候補で、Unicode全体を網羅するものではありません。パレットの使用履歴は保存せず、通信も行いません。

かなは中央・左・上・右・下の順に「あ・い・う・え・お」です。「ホールド＋往復」では、左へ出て中央へ戻ると濁音、右往復ではは行の半濁音／他の対応かなの小書き、上往復では数字へ切り替えます。中央で止まる必要はなく、中央を通って反対側まで動かしても往復を認識します。その後、最後のフリック位置で文字を選びます。「か」の左往復後に上へフリックすると「ぐ」です。同じ往復で解除でき、別の修飾では後の修飾を使います。指を離すまで文字は入りません。境界を指定して読みを始めると、最初のかな1文字から予測候補を表示します。

選んだ文字の位置で指を止めてホールドすると、読み・送りの境界を指定します。移動中はホールドとして数えません。境界が有効になったときにガイドを更新し、設定がオンで振動できる場合は一回振動します。そのまま静止しても繰り返しません。ホールドした後でも指を動かすと境界を取り消し、同じ接触中に改めてホールドが成立すれば再び一回振動します。最後の位置で静止し、そのまま離した場合だけ境界を入力します。「小゛゜」は入力後の直前かなを濁音・半濁音・小書きへ循環します。

フリックガイドは十字形で、中央を触れているキーの中心に重ねます。周囲には中央へ戻る向きの矢印と「゛」「゜」「小」や各キーの数字を、主文字より小さく薄く表示します。矢印は文字ではなく線で描画します。修飾の選択中はチェック、解除方向には取り消し線を表示します。中央には選択中の文字、周囲には方向別の候補を表示し、拡大・縮小のアニメーションは使いません。

右列の「⇧」は全ての面で読み開始・送り境界に使えます。例えば「⇧」→英字面から`API`→「変換」で、英字の大小を保持した読みを検索します。英字はローマ字かな入力を通しません。`a/A`は次の英字の大小を切り替え、大文字だけでは読みを開始しません。`APIのせってい`のような混在読みも入力できます。

ホールドを使わない場合は、「⇧」→語幹→「⇧」→送りのかなで送りあり変換を行えます。次のかなを入れる前に「⇧」をもう一度タップすると送り境界を解除します。ホールド境界でも同じ送り指定を行えます。送りありの登録を取り消すと、語幹と送りを合わせた送りなしの読みに戻ります。例えば「り*よ」の登録を取り消すと「りよ」になり、続くかなはそのまま読みの末尾へ追加できます。英字・数字の末尾だけから送りを推定しません。

かな面の文字種キー（切替先の「ア」または「あ」）を上へフリックすると、読み開始時がひらがなならカタカナ、カタカナならひらがなへ変えて読みを確定します。右へフリックすると半角カナへ確定します。英字の大小・幅と数字の幅は変えません。タップは次のかなの文字種だけを切り替えます。「カナで確定」「半角カナで確定」のガイドは、操作対象の読みや候補があるときだけ表示します。通常入力中や登録本文に内側の読みがない場合は表示しません。候補表示中は元の読み、登録中は内側の読みに適用します。

10キーの同時押しは対応せず、追加の指が触れると接触を取り消します。入力欄の変更、文字面の非表示、画面の再構成でも未送信の操作を取り消します。保護欄では文字を直接入力し、境界指定・変換・直前かなの変更は行いません。

右列の空白キーは通常入力では空白記号「␣」、変換操作ができる状態では「変換」と表示します。右下は未確定入力があるときは「確定」、ないときは輪郭のあるEnter記号「⏎」や入力先の「送信」などになります。

基本操作と今回のUI調整はAndroid 30のエミュレーターで確認しています。実機の操作感と振動は未確認です。全配置と制約は[10キー入力の試作仕様](ten-key-input-design.md)を参照します。

## 入力例

以下は物理キーボードの標準的な初期設定を使う例です。`C-j` は Ctrl を押しながら j で、最初の `C-j` はひらがなモードに切り替えます。`Nihon` や `KaKu` の大文字は Shift を押しながらの入力です。候補は例示した辞書項目があることを前提にしています。別の候補を選ぶ場合は Space で移動できます。

| 入力 | 動作 |
| --- | --- |
| `C-j` → `Nihon` → Space → （候補「日本」）→ `C-j` | 送りなしで「日本」を改行せず確定します。 |
| `C-j` → `KaKu` → （候補「書く」）→ `C-j` | 送りありで「書く」を入力します。送り仮名まで打つと候補が表示されるため、Space は不要です。 |

## 対応する SKK の機能

| 分類 | 対応内容 |
| --- | --- |
| 入力モード | ひらがな、カタカナ、半角カタカナ、直接入力、全角英数。半角カタカナの物理キーは設定で割り当てます。 |
| ローマ字入力 | 標準規則と AZIK を選べます。「ローマ字の打ち方」で切り替えます。AZIK では `q` が `ん`、`[` がかな切替です。[AZIK の対応範囲](azik-profile.md)。 |
| 変換 | 送りなし・送りあり、英数見出し（abbrev）、接頭辞・接尾辞、[数値変換の対応形式](numeric-design.md)。 |
| 日付入力 | かな入力の待機中に `@` で今日の日付を選べます。元号・全角数字、西暦・日本語、ISOの三形式と、[限定した日付式](date-input-design.md)に対応します。 |
| 単語登録 | 入力中の登録、登録中の再帰的な変換と登録。 |
| 学習・候補管理 | 候補の学習、登録候補の削除、システム候補の非表示。 |
| 補完 | 読みの補完、個人辞書の動的補完（初期設定では無効）。 |
| 候補表示 | 候補一覧と注釈、画面キーボードの予測候補。 |

## 今日の日付を入力する

かな入力モードで読みや未消化ローマ字がないときに `@` を入力すると、今日の日付の候補が出ます。Spaceで形式を選び、通常の変換と同じ操作で確定します。元号・全角数字、西暦・日本語、ISO形式を用意し、選んだ形式を学習した後も日付は次の検索時に更新します。既存の個人辞書の `today` 候補を優先し、組込み日付辞書を最後に合成します。同じ式の候補は由来をまとめ、削除・非表示指定を優先します。

読みの入力中、abbrev、直接入力、全角英数の `@` は日付入力を始めません。日付候補は予測一覧には含めません。対応する辞書式と日付境界の扱いは[日付入力仕様](date-input-design.md)を参照します。

## HerissonSKK の画面操作と候補表示

物理・QWERTYでは大文字で、10キーでは「⇧」（読み開始）またはホールド境界で見出し語を開始すると前方一致の予測候補が出ます。予測候補はタップして選択します。見出し語入力中の右下「確定」は、候補を選ばず、表示中の読みを1文字も変えずに確定します。予測の検索中や取得不能の場合でも読みを確定できます。予測にはページ送りがありません。検索完了で候補がない場合は読みそのものが候補になります。Spaceで通常変換へ進むこともできます。

未完のローマ字入力から、使用中の規則で到達できる出力を予測します。標準規則では子音だけの途中入力も対象で、`n`は、な行と`ん`の両方を含めます。送りをまだ入力していない段階でも、辞書に明記された送りや実際に学習した送りを持つ候補は、その送りを付けて予測表示します。送り条件を持たない外部辞書の語幹だけから活用形は生成しません。

QWERTYのフリックの記号割当はキー上の小さな文字で確認できます。ガイドは約200ミリ秒の長押し、または上下フリック開始時に表示され、現在の入力対象を強調します。

Spaceによる通常変換では、入力先に読みを残し、候補を一覧だけに表示します。Spaceで次のページへ移り、物理・QWERTYの`x`で前のページへ戻れます。左右の三角も使えます。最後のページの右三角は無効です。その先でSpaceを押すと登録へ進みます。右下の「確定」は表示ページの先頭を確定し、改行・送信はしません。ほかの文字を入力すると先頭候補を確定してからその文字を通常入力します。Backspaceは変換を取り消して読みに戻します。未確定入力がないときだけ、右下の「⏎」「送信」などが入力先の改行／アクションを行います。

QWERTYのモードキーはひらがな／直接入力を切り替え、長押しで5種類のモードを選べます。見出し語・予測中は読みそのもの、通常変換中は表示ページ先頭を確定してから切り替えます。入力方法の切り替えは画面の「IME切替」またはCtrl+Spaceです。

物理キーボード接続中は既定で文字キーと画面下の予約領域をなくします。「画面キーボードとモード表示」から画面キーの併用へ変更できます。物理入力のモード変更は短時間の表示、候補一覧と再帰登録はポップアップです。カーソル位置を取得できない場合は、モードを右下、候補・登録を左上へ表示します。

物理キーボードの Enter は既定で確定に続けて入力先の改行／アクションを実行します。確定だけにしたい場合は設定の「未確定中のEnterを確定だけにする」を有効にします。候補が複数ある場合、Space で次候補へ、`x` で前候補へ戻せます。`/API` と Space で「エーピーアイ」を確認できます。`Ctrl+q` は次のキーの引用です。半角カナは初期割当がなく、設定でキーを割り当てます。見出し語中は矢印・Home/End・Backspace/Deleteで内部編集できます。入力規則や操作キーは設定画面から変更できます。候補表示中の `X` で削除対象を確認し、`y` で削除・非表示、`n` で戻ります。システム候補の非表示は辞書管理画面から解除できます。

## ローカル辞書と登録

ネットワークからは公式S・L・人名・地名・郵便番号辞書の一覧、または公開HTTPS URLを指定して導入できます。取得後のプレビューを確認し、「保存」で保存します。保存済みの取得元がある辞書は更新アイコンで手動更新できます。通信失敗・中止では以前の辞書を使い続けられます。自動更新はありません。郵便番号辞書の配布元更新は2022年5月で、最新の住所変更を保証するものではありません。

設定画面の「辞書の管理」で＋を押し、配布辞書・HTTPS URL・ファイルを選びます。ファイルはUTF-8、EUC-JP、EUC-JIS-2004のSKKテキストです。自動判定はこの順に復号を試すため、EUC-JPでも読めるEUC-JIS-2004の辞書は文字コードを明示指定してください。追加システム辞書は個人辞書と別に保存します。上にある辞書ほど優先し、ハンドルをドラッグして並べ替えます。ハンドルの選択から上下への移動もできます。ゴミ箱から確認の上で削除します。適用前に文字コード・件数・重複を表示します。許可した現在日付・相対日付式と二つの固定形式は日付候補として取り込みます。認識できる非対応の日付式・削除抑止式・空見出しは警告付きで除外し、対応する候補を取り込みます。日付式の範囲は[日付入力仕様](date-input-design.md)を参照します。除外後に候補が残らない辞書や不正な構文は適用しません。取り外しはアプリ内の対象システム辞書だけに作用し、選択元のファイルや個人辞書を削除しません。

個人辞書はマージと全置換を選べます。全置換前には「個人辞書をファイルに保存」で退避してください。書き出しはUTF-8・BOMなし・LFです。標準 SKK テキストには候補の非表示指定やシステム辞書の管理情報が含まれません。「全辞書をバックアップ・復元」は辞書全体・優先順・非表示候補・予測の使用履歴を別形式で扱います。

未登録語の変換は単語登録へ進みます。登録本文と内側の変換はIME内で表示し、最上位の保存成功後だけ入力先へ確定します。物理Enterは内側の読み・候補・残余があるときはその確定だけ、次のEnterは単語の保存です。画面の右下キーも内側の確定後に登録を保存し、登録見出しの「取消」は現在の登録階層を取り消します。Ctrl+gは内側から取り消します。保存中に入力欄を切り替えた場合、受理済みの保存は完了する場合がありますが、遅い完了が別の入力欄へ文字を挿入することはありません。

「入力から単語を登録・学習する」をオフにすると、新しい入力由来の保存と待機中の保存を抑止します。入力先の学習禁止要求でも登録保存を抑止します。設定画面から明示する辞書取り込みは別操作です。

数値変換は初期状態で有効です。数字を含む見出しを `#` に正規化して検索し、`#0`〜`#5`、`#8`、`#9` を展開します。学習と登録は元テンプレートを保存し、表示した展開結果だけを入力先へ確定します。詳細と資源上限は[数値変換仕様](numeric-design.md)を参照します。

見出し語の末尾でTabを押すと通常補完し、続くTab／Shift+Tabで候補を移動します。Ctrl+gは補完前の読みに戻します。設定の「個人辞書の動的補完」は既定でオフです。有効化は次の入力欄から反映し、未受諾部分を【】と別書式で表示します。Rightで受諾し、Spaceは提案を使わず入力済みの読みだけを変換します。


## 入力設定と外部編集

「ローマ字の打ち方」「句読点と記号」「候補の表示と選び方」「キー操作とEmacs編集」から目的の設定を開きます。ローマ字入力規則は標準規則、AZIK、カスタム規則から選べます。各画面で編集し、画面下部の「保存」で保存して上位画面へ戻ります。未保存で戻ると、保存・破棄・キャンセルを選べます。「標準に戻す」は開いている画面の設定だけを変更します。保存した設定は次の入力欄から反映します。変更が競合した場合は保存せず通知し、標準へ戻す操作も用意しています。[入力設定設計](customization-design.md) と [AZIK の採用範囲](azik-profile.md) を参照します。

「キー操作とEmacs編集」では適用範囲を「無効」「IME 内のみ」「IME とアプリ」から選びます。初期値は「無効」です。「アプリごとの編集キー」でアプリ名またはパッケージ名を検索し、全体設定の継承またはそのアプリ用の範囲を選べます。アプリのショートカットと衝突するときはそのアプリだけ無効にできます。この画面の変更は選択時に保存され、次の入力欄から適用します。

Emacs 編集キーを有効にした範囲では、Ctrl+a/e/b/f/p/n/h/d/k、Alt+b/f で内部編集または対応する入力先の編集を行います。Ctrl+p/n は上下移動です。保護欄では迂回します。入力先の対応状況や取得できる本文・選択範囲によって利用できない操作があります。入力先との同時編集を原子的に保証できない制約は [編集設計](emacs-editing-design.md) に記載しています。

一覧の候補本文は省略せず折り返します。画面キーボードでは横幅に合わせて表示件数を減らし、一件でも長い場合は高さを広げます。非常に長い本文は候補内をスクロールして確認できます。画面キーボードの補完・変換候補には注釈を表示せず、候補本文と区切りだけを表示します。候補を長押しすると、入力先とキーボードの高さを変えずに重なるポップアップで注釈を確認できます。長い注釈は窓内をスクロールして全文を読めます。候補間だけに淡い細い縦線を置き、注釈がある候補には下線を付けます。物理キーボード使用時のカーソル近傍の候補メニューは、右側に注釈を一行で表示します。指を離すだけでは確定しません。注釈窓には閉じるボタンを置かず、窓外へのタッチ開始または戻る操作で閉じます。窓外では最初のタッチから背後のキーや候補を操作でき、タップ・長押し・フリックを続けられます。[入力UI再設計](input-ui-design.md)を参照します。

## 完全辞書バックアップ

「辞書の管理」→「完全辞書バックアップ・復元」で保存先を選びます。個人辞書、全システム辞書（無効な辞書を含む）、優先順、候補の非表示指定、予測の使用履歴を平文で保存します。入力設定と入力先の本文は含みません。

復元は全ファイルの検証後、件数と置換対象を確認して適用します。確認後に辞書が変更された場合は適用せず、選択し直します。「復元は保存済み、入力への反映に失敗」と表示された場合は再反映だけを行い、復元を再適用しません。詳細な上限は [完全バックアップ設計](complete-backup-design.md) を参照してください。

## 編集キーと物理キーボードの設定

Emacs編集を有効にした入力先では、Ctrl+/ は入力先のUndo、Ctrl+y はPasteを呼び出します。Ctrl+kで削除する文字列はAndroidのクリップボードへコピーします。入力先が操作を実装していない場合は実行できません。

アプリIDは `se.haya.skk` です。

「物理キーボードの配列」はAndroidの設定画面を開きます。そこでの「画面キーボードを使用」は、物理キーボード接続中も画面キーボードを併用するOS側の設定です（[Androidヘルプ](https://support.google.com/android/answer/14114879?hl=ja)）。IME独自の「物理キーボード接続中は画面の文字キーを隠す」とは別の設定です。
