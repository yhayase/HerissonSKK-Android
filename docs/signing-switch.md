# 署名が異なる APK 間でのデータ移行

Android は、アプリ ID が同じでも署名証明書が異なる APK を上書き更新できません。たとえば開発署名 APK から Google Play の署名済み APK に切り替える場合、先に辞書を完全バックアップし、移行先をインストールしてから復元します。アプリ ID と署名証明書が一致する通常の更新は[更新検証](upgrade-validation.md)に従います。

## 手順

1. 現在のアプリで「完全辞書バックアップを保存」を実行し、生成ファイルを端末内の分かる場所へ保存します。入力設定、キー割当、アプリ別 Emacs 設定も記録します。
2. バックアップが保存され、復元に使えることを確認してから、現在のアプリをアンインストールします。同じアプリ ID の APK は署名が異なると同時にインストールできません。
3. 移行先 APK をインストールし、入力方法を有効にします。
4. 「完全辞書バックアップから復元」で保存したファイルを選びます。復元先の辞書全体が置き換わるため、移行先に残したい辞書がある場合は、先にそのバックアップも保存します。
5. 辞書件数・候補数を確認し、システム辞書の語と個人登録語を変換できることを確認します。移行を確認するまでバックアップファイルを保持します。

完全バックアップには個人辞書、システム辞書、有効状態・優先順、候補の非表示指定、候補使用履歴が含まれます。入力設定、キー割当、アプリ別 Emacs 設定、Android 側の IME 選択は含まれないため、手順1で記録した設定を移行先で再設定します。バックアップ形式と読込み互換性は[完全バックアップ設計](complete-backup-design.md)を参照してください。
