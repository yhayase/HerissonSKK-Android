# 設定画面の構成

設定画面の階層、保存、操作を定めます。

## 基本構成

AndroidX Preferenceの標準の項目・カテゴリ・スイッチ・選択ダイアログを使います。設定名はtitle、現在値はsummaryに分けます。項目名と値を連結して一つのラベルにしません。キー割り当てはEditTextPreferenceの標準入力ダイアログで編集し、現在値は十分なコントラストで表示します。標準値を常時併記しません。通常の設定トップは「入力」「表示」「辞書」「その他」に分け、初期設定への入口を最下部に置きます。操作マニュアルは設定項目へ混ぜません。

一つの編集画面では一つの目的だけを扱います。ローマ字、句読点、候補、キー操作の画面内にカテゴリを切り替えるプルダウンを置きません。ローマ字規則はプロファイルと規則一覧を表示し、一行を選んで編集します。辞書は現在利用する辞書を優先順に表示します。ハンドルのドラッグで並べ替え、ゴミ箱から確認の上で削除します。有効・無効の切替は置きません。追加はフローティングの＋から配布辞書・HTTPS URL・ファイルを選びます。更新は保存済みの取得元を使い、その場で別ファイルへ置き換える選択肢を置きません。

画面名と戻る操作は上部に固定します。編集画面の「標準に戻す」「保存」は下部に固定し、本文だけをスクロールさせます。狭い画面でも二つのボタンを一行に置きます。広い画面では本文と操作部の幅を最大720dpに制限し、選択操作や値を遠い画面端へ引き離しません。選択肢は横長のプルダウンではなく、行の現在値と標準の選択ダイアログで示します。

## 保存・戻る・標準化

- 変更は画面の下書きに保持します。「保存」が成功してから上位画面へ戻ります。失敗時は下書きを保持します。
- 未保存で戻るときは「保存して閉じる」「破棄」「キャンセル」を選びます。上部の戻る操作とOSの戻る操作は同じ意味です。
- 独立した「破棄して閉じる」「保存済み設定を再読込する」ボタンを置きません。
- 「標準に戻す」はその画面の設定だけを下書き上で標準化します。確認の取消側は「キャンセル」です。個人辞書を削除しません。
- ローマ字などの保存は世代の競合を検出し、別画面で保存済みの設定を無言で上書きしません。

辞書の組み合わせには共通の標準値がないため、辞書管理の下部操作は「保存」だけです。画面を開いた時点へ戻す操作を「標準に戻す」とは呼びません。アプリ別の有効／無効はAndroidの通常の設定項目と同様に選択時に保存し、画面にもその適用時点を示します。

## 初期設定と辞書

初期設定を専用ページに分離し、IMEの有効化、IMEの選択、辞書の選択の順で扱います。初回のS辞書は独立した導入ボタンを要求せず自動で準備します。初回取得と以後の自動更新は区別し、定期・入力中の更新は行いません。取得不能時には失敗を示し、再試行または後からの設定を選べます。追加辞書は初期設定で選択します。Lを選んだ場合、Lの導入に成功してからSを置き換えます。取得・解析・保存に失敗した場合はSを維持します。初期設定での並び順は固定し、辞書管理では上にある辞書ほど優先します。

既知辞書の種類と取得元・ライセンスは[ネットワーク辞書](network-dictionary-design.md)を参照します。

## アプリ検索と設定値

アプリ別Emacs編集は常設の検索欄で、アプリ名とパッケージ名を大文字・小文字を区別せず絞り込みます。入力のたびに一覧を更新し、画面回転後も検索語を保持します。アプリ名を項目名、有効・無効の実効状態を現在値として分けて示し、全体設定からの継承か個別指定かを補足します。

## Emacs キーバインド

「Emacs キーバインド」という一つの ListPreference に、標準の単一選択ダイアログで「無効」「IME 内のみ」「IME とアプリ」を表示します。一覧には現在値を表示します。IME 外だけを有効にする選択肢は提供しません。

| 選択 | IME が管理する読み・登録など | 入力先アプリ |
| --- | --- | --- |
| 無効 | 編集キーを使いません | 編集キーを使いません |
| IME 内のみ | 編集キーを使います | 編集キーを使いません |
| IME とアプリ | 編集キーを使います | 編集キーを使います |

C-j、C-g などの SKK 本来の操作は、どの選択でも維持します。候補表示中のキーは候補操作の定義に従い、通常の本文編集とは区別します。

アプリ別設定では「全体設定に従う」に加えて同じ三択を使い、編集範囲全体を置き換えます。全体が「IME とアプリ」でも、個別に「無効」を選べば IME 内の編集も無効です。アプリ名とアプリ ID で絞り込みでき、一覧には実際の適用範囲と継承の有無を表示します。変更は次の入力欄から反映します。

## 検証

API 26・35で保存成功／失敗、未保存で戻る、標準化の取消、画面回転、設定世代の競合、辞書操作の対象を確認します。スマートフォンとタブレット相当の幅、大きな文字、画面キーボード表示中に、上部・下部操作を最下部へのスクロールなしで使えることを確認します。キー上のフリック記号は実際の描画で主文字との非重複・余白を確認します。

参照: [Androidの設定画面設計](https://developer.android.com/design/ui/mobile/guides/patterns/settings)、[Preferenceコンポーネント](https://developer.android.com/develop/ui/views/components/settings/components-and-attributes)。

## 辞書ソースと保存形式

配布辞書は`SKK-JISYO.S`などの正式なファイル名で表示します。ファイル導入では選択した`content://` URIと永続読取権限を保存し、更新時には同じURIへの権限を照合します。権限はバックアップへ移せないため、復元先などで権限がない場合は元ファイルから再追加します。取得元を記録していなかった旧辞書も再追加が必要です。

個人辞書のファイル保存はSKKテキスト形式で登録・学習済み候補を持ち出す操作です。完全バックアップは辞書・優先順・非表示候補・予測の使用履歴をまとめて復元するための別形式です。入力設定自体のバックアップとは区別します。

並べ替えには[RecyclerViewのItemTouchHelper](https://developer.android.com/reference/androidx/recyclerview/widget/ItemTouchHelper)、ファイル権限には[Storage Access Frameworkの永続アクセス](https://developer.android.com/training/data-storage/shared/documents-files)を使います。

## 標準部品を使う原則

標準部品で実現できる表示や操作を独自実装しません。セクションはPreferenceCategory、単一選択はListPreferenceまたはRadioGroup、複数選択はCheckBoxPreference、オン／オフはSwitchPreferenceCompat、文字列の編集はEditTextPreferenceを使います。見出しを通常のPreferenceや色付きTextViewで代用しません。文字サイズ・余白・区切りは標準テーマと部品に任せます。

画面内はカテゴリとその配下の設定項目という階層にします。初期設定の有効化・選択・完了は設定値ではないため、対応する操作と状態を分けて示します。アプリ固有の項目の厳密な並び順をAndroidが規定しているわけではないため、初期設定は操作の依存順、通常設定は目的別にまとめます。従来承認された保存・破棄の下書き操作は維持します。

独自処理が必要な場合も、既存部品のレイアウトを作り直さず、必要な動作だけを追加します。辞書のドラッグ並べ替えなど、Preferenceにない機能は例外の理由と範囲を記録します。単に見た目を揃えるための独自ViewやonMeasureは作りません。幅に応じた配置はAndroidのレイアウトリソースで定義します。

参照: [設定のグループ化](https://developer.android.com/develop/ui/views/components/settings/organize-your-settings)、[現在値のsummary表示と入力欄の設定](https://developer.android.com/develop/ui/views/components/settings/customize-your-settings)。


## 設定テーマ

設定画面は Material 3 の DayNight テーマを使います。Android 12 以降の対応端末では DynamicColors で端末の配色を反映し、それ以前は Material 3 の標準配色を使います。PreferenceCategory、SwitchPreferenceCompat などの設定階層・保存処理を維持し、スイッチ部分には標準の MaterialSwitch を組み込みます。色・形・状態描画は標準ウィジェットに任せ、特定の紺色には固定しません。ツールバー、ボタン、確認ダイアログも Material Components を使います。
